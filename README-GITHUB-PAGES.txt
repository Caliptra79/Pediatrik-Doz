# Pediatrik Doz Hesaplayıcı — PWA

Bu klasör GitHub Pages için hazırdır.

## GitHub Pages
1. GitHub'da yeni bir repository oluşturun.
2. ZIP'i açın ve içindeki **tüm dosyaları** repository'nin köküne yükleyin.
3. Repository → Settings → Pages.
4. Source: **Deploy from a branch**
5. Branch: **main** / **root**
6. Save.
7. GitHub'ın verdiği Pages adresini iPhone Safari'de açın.
8. Paylaş → **Ana Ekrana Ekle**.

## Önemli
PWA'nın çalışması için `index.html`, `manifest.webmanifest`, `sw.js` ve `icons` klasörü aynı kökte kalmalıdır.
